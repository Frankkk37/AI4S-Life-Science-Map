# AI4S Life Science Map

Interactive panorama of 14 core papers for understanding AI for Life Science.

## What this map shows
- Biological scale
- Model input / output
- Training data
- Task type
- Validation method
- Bottleneck displaced

The map is intentionally non-linear: the papers sit around different biological scales and interfaces rather than forming a single sequential technology stack.

Open `index.html` or visit the GitHub Pages site once Pages is enabled.
