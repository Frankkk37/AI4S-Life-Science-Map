AI4S 一张图综合网络图 / Unified AI4S Network Map

这版把 Core Loop、技术分支、公司节点、公司之间的高信号关系 合并到了同一张大图中： 中间是闭环，外圈沿各主干向外延伸的是公司。公司多的分支继续向外、向下铺开。 其中，浅灰线表示公司挂靠在哪个主干；蓝灰粗线表示闭环本身；橙色虚线表示精选的公司—公司关系（如生态/孵化、设备—编排、代表性工具链关系），数量刻意控制，避免整张图变成“毛线团”。
如何阅读 / How to read： 先顺着闭环读一圈：AI模型 → 设计 → Build → 生物模型 → 实验执行 → Readout → 数据与学习 → AI模型； 再看某个主干外侧挂了哪些公司；最后看少量高信号的公司—公司关系。 这一版使用上一轮的 131 家核心公司池，并新增少量关系型生态伙伴节点。公司—公司关系层现已扩展为 35 条有公开证据支持的关系；点击关系线本身即可在右侧查看关系类型、说明、来源等级和原始链接。

真正的 Loop / The actual loop
主干之间不是并列分类，而是一条闭环。
模型提出假设 → 变成设计 → 真正 Build → 放入生物系统 → 自动化执行 → Readout 采集 → 数据/QC/学习 → 再回到模型。
类器官、器官芯片属于“生物模型”；机器人属于“实验执行”；测序、单细胞、成像、质谱属于“Readout”。
公司之间的关系怎么画？
只保留有公开证据支持的高信号关系；当前已核验 35 条。
